## 1. 기본 흐름 테스트 (약 5분)

좌측 메뉴 순서대로 진행합니다.

### 1️⃣ EDA
1. **🧪 샘플 생성** 탭 → 유형 **"현실 시나리오"** 선택
2. 행 수 `1200`, 이상 비율 `0.1`, **이상 난이도 = 보통** → **🧪 샘플 생성**
3. **🔍 EDA 실행** 클릭

**확인 포인트**
- 데이터 개요·클래스 분포(불균형비)·결측·기초 통계량·데이터 품질(IQR 이상치)
- **정상 vs 이상 피처 분포 비교** — 어떤 센서가 이상을 잘 가르는지
- **상관관계 히트맵**, **시간 의존성 진단**(자기상관 → LSTM 권장 여부)
- 각 항목의 **💡 해석 가이드**

### 2️⃣ 모델 생성
1. (선택) **⚙️ 학습 설정**에서 epoch·병목 차원·임계값 백분위수 조정
2. 새 모델 이름 입력 → **🚀 학습 시작**

**확인 포인트**
- 학습 **진행률 바**(epoch·loss·val_loss 실시간)
- 학습 품질: **손실곡선**, **오차분포+임계값**, **ROC/PR 곡선**
- 시계열 데이터(아래 3번)면 학습 시 **LSTM 선택 팝업**

### 3️⃣ 모델 평가 — 5가지 방식
| 방식 | 확인 내용 |
|---|---|
| **🕐 시간분할 검증(권장)** | 과거 학습 → 미래 평가. F1 등 표준지표 + **에피소드 검출률·탐지 지연·오경보율** |
| ⌨️ 단일 샘플 판정 | 센서 값 직접 입력 → 즉시 판정. **여러 건 입력(표)** 모드도 확인 |
| 📄 테스트셋 파일 평가 | 다른 CSV 업로드 → 판정·지표·개별 진단 |
| 📊 모델 비교 | 모델 2개 이상 학습 후 동일 데이터로 비교, **최고 모델 활성 지정** |
| 🎚 임계값 정책 | **오경보 허용량 역산**, **미탐/오탐 비용 최적화** |

### 4️⃣ 성능 모니터링
1. 운영 데이터 CSV 업로드(EDA에서 만든 데이터를 내려받아 사용 가능)
2. 구간 기준·**드리프트 판정 방식(z-score/PSI/KS)**·민감도 조정

**확인 포인트**
- 드리프트 상태(🟢🟡🔴)와 경고 시 **재학습 권고**
- 구간별 오차 추이(드리프트 구간 X 표시), **구간 표의 드리프트 열**
- **🔔 알람 정책(디바운싱)** — K/M 규칙으로 알람 횟수 감소 확인
- **기간 필터**, **기준선 재설정**

## 2. 중점 검증 시나리오

### A. 임계값 교정 효과 (V1)
- 모델 생성 후 **모델 평가 → 🎚 임계값 정책**에서 "현재 임계값의 오경보율" 확인
- 학습 시 정상 데이터의 20%를 **보정용으로 분리**해 임계값을 산출하므로, 학습 데이터에서
  산출할 때보다 오경보가 적습니다(측정치: 2.9% → 1.4%).

### B. 난이도에 따른 성능 변화 (V5)
- EDA에서 난이도만 바꿔(미세 / 보통 / 뚜렷) 각각 데이터 생성 → 학습 → 시간분할 검증
- **미세 난이도에서 F1이 뚜렷하게 낮아지는지** 확인(측정치: 0.731 / 0.925 / 0.934)
- 실제 데이터에 가까운 조건에서 모델·설정 튜닝을 검증할 수 있습니다.

### C. 운영 관점 판단 (V2·V3)
- **시간분할 검증**의 에피소드 검출률·탐지 지연을 봅니다(샘플 F1보다 현장에 가까움)
- **임계값 정책**에서 "하루 10건 이하 오경보" 같은 목표를 넣어 권장 임계값 확인
- **알람 정책**에서 K/M 값을 바꿔 알람 횟수 변화 확인

### D. 시계열 모델 (LSTM)
- EDA → 샘플 생성에서 유형 **"시계열(자기상관)"** 선택 → 생성
- 시간 의존성 "높음" 배지 확인 → 모델 생성 시 **팝업**에서 LSTM 선택
- LSTM은 연속 구간이 필요해 단일 샘플 판정은 미지원(안내 표시됨)

### E. 모델 관리
- 여러 모델 학습 후: **F1순 정렬**, **태그 필터**, 이름/메모/태그 편집
- **호환성 배지**(다른 컬럼 구성의 CSV를 올리면 ⚠️ 표시)
- **전체 모델 zip 내보내기/가져오기**(사내 이관용)

## 3. 알려진 제약 / 참고

- **모델 저장 위치**: 로컬 `models/` 폴더(gitignore). 클라우드 배포 시 재시작하면 사라집니다.
- **알림·자동 재학습**: 미구현 — 현장 적용 단계에서 사내 SMTP/웹훅 연동 예정.
- **Oracle 연동**: 코드 스켈레톤만 존재(`src/db.py`, `src/batch_infer.py`).
  실제 접속은 사내 DB 설계 확정 후.
- **다중 운전 모드**: 데이터 생성 시 모드 수를 늘릴 수 있으나, 모드별 개별 모델 학습은 미구현
  (사내 데이터 확보 후 V4에서 검토).
- 첫 학습은 TensorFlow 로딩으로 수십 초 걸릴 수 있습니다.
